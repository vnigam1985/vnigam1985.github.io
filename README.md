# Vishal Nigam | Portfolio

Personal site. Built from [cloud-portfolio-template](https://github.com/vnigam1985/cloud-portfolio-template).

- Edit content: `src/portfolio.config.ts`
- Photos and video: `public/media`
- Hero video guide: `docs/HERO-VIDEO.md`
- Deploys to GitHub Pages on every push to `main` (Settings > Pages > Source: GitHub Actions)

```bash
npm install
npm run dev
```
